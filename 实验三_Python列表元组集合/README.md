## 任务与核心结论

| 任务 | 内容 | 关键结论 |
| --- | --- | --- |
| 任务1 | 切片删除深度探究 | `del ls[::3]` 按删除前索引一次性定位再统一删除；`del ls[::-2]` 从末尾每隔一个往前删 |
| 任务1 拓展 | 循环中删除元素 | for 内部下标自增，删除导致元素前移，出现漏删；`[2,4,6,8]` 删偶数后剩 `[4,8]` |
| 任务2 | 嵌套容器可哈希 | `(1,2,3)` 可入集合，`(1,[2,3])` 报 TypeError；`frozenset` 可嵌套 |
| 任务3 | 集合运算 + 推导式 | 交集 `{6,12}`、并集 9 个元素、对称差 `{2,3,4,8,9,10,15}`；推导式得 7 个数 |
| 任务4 | 去重算法对比 | `list(set())` 乱序；`dict.fromkeys` 保序且快；手写 `in list` 慢约 600 倍 |
| 任务5 | 选课综合统计 | 交集 `{107,109}`、对称差 7 人、并集 9 人，人数校验自洽 |

## 结果摘要

- 切片删除：三组预判与实际完全一致，脚本内用 `assert` 自校验。
- 可哈希测试：2 条成功、3 条 TypeError，报错信息均已记录并解释。
- 集合运算：五种运算结果正确，方法写法与运算符写法等价。
- 去重性能（2 万条）：`list(set())` 0.00056s、`dict.fromkeys` 0.00060s、辅助 set 0.00094s、手写循环 0.54377s。
- 选课统计：交集 2 人 + 对称差 7 人 = 并集 9 人；两个差集 3 + 4 = 对称差 7 人。
