## 1. 核心目标

1. 读取指定的销售原始数据 `sales_raw.xlsx`，完成数据清洗。
2. 按销售员、地区、月份三个维度统计销售额，生成一份 Excel 报表。
3. 一次运行输出 4 个工作表：明细清洗后、按销售员、按地区、总览。
4. 全过程只读原始文件，不修改、不覆盖输入数据。
5. 对空文件、无有效数据、字段缺失等情况给出明确错误，不静默失败。

**非目标（本期不做）**：多文件合并、数据库存储、Web 界面、图表大屏、增量更新、历史报表对比。

---

## 2. 输入说明

### 2.1 文件要求

| 项目 | 要求 |
|---|---|
| 文件名 | 默认 `sales_raw.xlsx`，可通过 `--input` 指定其他路径 |
| 格式 | 仅支持 `.xlsx`；不处理 `.xls`、`.xlsm`、`.csv` |
| 工作表 | 默认读取第一个工作表；可通过 `--sheet` 指定名称或序号 |
| 表头位置 | 第 1 行必须是字段名 |
| 列顺序 | 不固定，按列名识别；多余列忽略并记录警告 |
| 编码/语言 | 中文列名，UTF-8 |

### 2.2 字段定义

| 字段 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| 日期 | 日期 | 是 | 2026-03-15 | 支持 Excel 日期、`YYYY-MM-DD`、`YYYY/M/D` |
| 销售员 | 文本 | 是 | 张三 | 去除首尾空格后不能为空 |
| 产品 | 文本 | 是 | A 型电机 | 去除首尾空格后不能为空 |
| 数量 | 整数 | 是 | 12 | 必须为正整数 |
| 单价 | 数值（2 位小数） | 是 | 199.50 | 单位：元 |
| 地区 | 文本 | 是 | 华南 | 去除首尾空格后不能为空 |

### 2.3 脏数据类型

| 类型 | 示例 | 期望处理 |
|---|---|---|
| 空单元格 / 空白字符串 | 销售员为空 | 剔除整行并计数 |
| 重复行 | 六字段完全一致的两行 | 保留第一条，删除后续重复 |
| 负数量 / 零数量 | 数量 = -3、0 | 剔除整行并计数 |
| 非数值数量/单价 | “十台”“abc” | 剔除整行并记录行号 |
| 日期无法解析 | “下周一”“2026-13-40” | 剔除整行并记录行号 |
| 首尾空格 / 全角空格 | “ 张三 ” | 清洗后继续使用 |
| 多余列 | 备注、内部编号 | 忽略，记录警告 |

## 3. 输出说明

### 3.1 文件要求

| 项目 | 要求 |
|---|---|
| 文件名 | `sales_report_YYYYMMDD_HHMMSS.xlsx`，避免覆盖历史结果 |
| 输出目录 | 默认 `output/`；可通过 `--output` 指定完整路径 |
| 工作表数量 | 固定 4 个 |
| 工作表顺序 | 明细清洗后 → 按销售员 → 按地区 → 总览 |
| 格式 | 表头加粗、冻结首行、金额 `#,##0.00`、日期 `yyyy-mm-dd`、列宽自适应 |

### 3.2 工作表内容

| 工作表 | 列 | 说明 |
|---|---|---|
| 明细清洗后 | 日期、销售员、产品、数量、单价、地区、销售额 | 每行一条有效记录，按日期升序、日期相同按销售员升序 |
| 按销售员 | 销售员、销售额、明细行数、销售额占比 | 按销售额降序，销售额相同按销售员升序 |
| 按地区 | 地区、销售额、明细行数、销售额占比 | 按销售额降序，销售额相同按地区升序 |
| 总览 | 指标、数值 | 原始行数、有效行数、剔除行数、重复行数、总销售额、销售员数、地区数、日期范围、生成时间；另含“月度总额”小表（月份、销售额） |

---

## 4. 数据清洗规则

按以下顺序执行，前一步的输出是后一步的输入。

| 编号 | 规则 | 处理方式 |
|---|---|---|
| CR-01 | 读取工作表 | 只读模式打开；空文件或无工作表时报 E-005 |
| CR-02 | 字段校验 | 6 个必填列任一缺失即终止，报 E-002 并列出缺失列名 |
| CR-03 | 文本标准化 | 去除首尾空格（含全角空格）；销售员、产品、地区为空视为缺失 |
| CR-04 | 关键字段缺失 | 6 个字段任一为空，剔除整行并计入“缺失剔除数” |
| CR-05 | 日期转换 | 统一转为日期类型；无法解析则剔除并记录行号 |
| CR-06 | 数量转换 | 转为整数；非整数（如 3.5）或非数值视为异常并剔除 |
| CR-07 | 数量约束 | 数量 ≤ 0 的行剔除，计入“数量非法剔除数” |
| CR-08 | 单价转换 | 转为 Decimal；非数值剔除；负单价剔除并记录（单价为 0 的处理见待确认项 Q-01） |
| CR-09 | 全字段去重 | 在 CR-03～CR-08 之后，按 6 个字段完全一致去重，保留第一条 |
| CR-10 | 计算销售额 | `销售额 = 数量 × 单价`，保留 2 位小数，四舍五入（ROUND_HALF_UP） |
| CR-11 | 原始文件保护 | 全程只读，不保存、不重命名、不移动原始文件 |
| CR-12 | 清洗日志 | 每类剔除数量写入总览和运行日志；被剔除行最多输出前 20 条行号与原因 |

## 5. 统计计算规则

| 编号 | 规则 | 说明 |
|---|---|---|
| ST-01 | 销售额 | 数量 × 单价，Decimal 计算，最终保留 2 位小数 |
| ST-02 | 按销售员汇总 | 对清洗后明细按销售员分组求和，输出销售额、明细行数 |
| ST-03 | 按地区汇总 | 对清洗后明细按地区分组求和，输出销售额、明细行数 |
| ST-04 | 月度总额 | 按“年-月”分组求和，结果放在总览工作表的“月度总额”小表 |
| ST-05 | 总销售额 | 所有有效明细销售额之和；必须等于按销售员、按地区汇总之和 |
| ST-06 | 占比 | 组销售额 ÷ 总销售额 × 100%，保留 2 位小数；因四舍五入，各组占比之和允许有 ±0.01 的误差 |
| ST-07 | 排序 | 汇总表按销售额降序；金额相同按名称升序 |
| ST-08 | 零值处理 | 汇总结果不输出销售额为 0 的组（正常情况下不会出现） |
| ST-09 | 日期范围 | 总览中的日期范围取有效明细的最小日期与最大日期 |
| ST-10 | 精度要求 | 全程使用 Decimal，禁止用 float 直接累加金额 |

## 6. 约束与异常处理要求

### 6.1 约束

1. 运行环境：Python 3.10+，依赖 pandas、openpyxl、xlsxwriter。
2. 不得修改原始文件；运行前后原始文件 SHA-256 必须一致。
3. 输出文件已存在时不得静默覆盖，使用时间戳命名或提示用户。
4. 同一输入重复运行，除生成时间与文件名外，4 个工作表内容必须一致。
5. 单实例运行；输出文件被占用时提示关闭后重试。
6. 处理 10 万行数据应在 60 秒内完成，内存占用不超过 1GB。

### 6.2 错误码与处理

| 错误码 | 场景 | 行为 |
|---|---|---|
| E-001 | 文件不存在、无读取权限、不是 .xlsx | 终止，提示完整路径与原因，退出码 1 |
| E-002 | 缺少必需字段 | 终止，列出全部缺失列名，退出码 1 |
| E-003 | 清洗后无有效数据 | 终止，不生成报表，提示各类剔除数量，退出码 2 |
| E-004 | 输出目录不可写 / 文件被占用 | 终止，提示目标路径，退出码 3 |
| E-005 | 空文件、无工作表、表头为空 | 终止并提示，退出码 1 |
| W-001 | 存在多余列 | 继续执行，日志记录被忽略的列名 |
| W-002 | 部分行被剔除 | 继续执行，总览记录剔除数量，日志列出前 20 条行号 |

**日志要求**：控制台输出一行摘要（原始行数、有效行数、剔除行数、总销售额、输出路径）；可选 `--log` 写入文本日志。

## 7. 验收标准

| 编号 | 验收场景 | 通过标准 |
|---|---|---|
| AC-01 | 使用标准样例 `sales_raw.xlsx` 运行 | 成功生成 1 个 xlsx，包含 4 个工作表，名称与顺序正确 |
| AC-02 | 明细正确性 | 抽查任意 3 行，日期、销售员、产品、数量、单价、地区、销售额与源数据及公式一致 |
| AC-03 | 空值清洗 | 关键字段为空的行全部被剔除，总览中的剔除数与预期一致 |
| AC-04 | 重复行清洗 | 六字段完全一致的重复行只保留一条，重复数统计正确 |
| AC-05 | 数量非法 | 数量为 0 或负数的行全部剔除，且不影响其他行 |
| AC-06 | 销售员汇总 | 每个销售员的销售额、明细行数正确；总额与明细合计一致 |
| AC-07 | 地区汇总 | 每个地区的销售额、明细行数正确；总额与明细合计一致 |
| AC-08 | 月度总额 | 各月份销售额正确，月份合计等于总销售额 |
| AC-09 | 金额精度 | 如 3 × 0.1、199.5 × 3 等用例结果保留 2 位小数且无浮点误差 |
| AC-10 | 字段缺失 | 删除任一必填列后运行，退出码 1，错误信息列出该列名，不生成输出文件 |
| AC-11 | 空文件 / 仅表头 | 退出码非 0，提示“无有效数据”，不生成输出文件 |
| AC-12 | 原始文件保护 | 运行前后原始文件 SHA-256 一致，文件修改时间不变 |
| AC-13 | 重复运行 | 连续运行两次，除时间戳文件名与生成时间外，4 个工作表内容一致 |
| AC-14 | 性能 | 10 万行输入在 60 秒内完成，内存占用 ≤ 1 GB |
