# Excel 销售报表生成脚本

读取销售原始数据，完成数据清洗与销售统计，输出一份包含 4 个工作表的 Excel 报表。

## 1. 功能简介

脚本按以下流程执行：

1. 读取 `sales_raw.xlsx`，校验必需字段；
2. 清洗空值、重复行、数量非法、数量/单价无法转换的行；
3. 计算每条明细的销售额（数量 × 单价，保留 2 位小数）；
4. 按销售员、地区汇总销售额，并计算总销售额；
5. 生成包含 4 个工作表的报表：
   - **明细清洗后**：完整的有效明细；
   - **按销售员**：销售员维度的销售额，降序排列；
   - **按地区**：地区维度的销售额，降序排列；
   - **总览**：月度总销售额。

**只读原始文件**，输出写入新文件，不会修改或覆盖输入数据。

## 4. 输入说明

输入文件为 `.xlsx` 格式，第 1 行为表头，必须包含以下 6 个字段：

| 字段 | 类型 | 必填 | 示例 | 说明 |
|---|---|---|---|---|
| 日期 | 日期 | 是 | 2026-03-15 | 支持 Excel 日期、`YYYY-MM-DD`、`YYYY/M/D` |
| 销售员 | 文本 | 是 | 张三 | 不能为空 |
| 产品 | 文本 | 是 | A 型电机 | 不能为空 |
| 数量 | 整数 | 是 | 12 | 必须大于 0 |
| 单价 | 数值 | 是 | 199.50 | 单位：元 |
| 地区 | 文本 | 是 | 华南 | 不能为空 |

列顺序可以调整，脚本按列名识别；多余列会被忽略。

## 5. 运行步骤

### 5.1 使用默认路径

将原始数据放到 `./data/sales_raw.xlsx`，然后执行：

```bash
python main.py
```

成功后在当前目录生成 `report.xlsx`，并输出：

```text
报表已生成至 report.xlsx
```

### 5.2 指定输入和输出路径

```bash
python main.py -i data/sales_raw.xlsx -o output/sales_report.xlsx
```

输出目录不存在时，脚本会自动创建。

### 5.3 查看帮助

```bash
python main.py --help
```

## 7. 输出说明

输出文件固定包含 4 个工作表，名称与顺序如下：

| 工作表 | 内容 | 主要列 |
|---|---|---|
| 明细清洗后 | 清洗后的有效明细，按日期升序 | 日期、销售员、产品、数量、单价、地区 |
| 按销售员 | 按销售员汇总，销售额降序 | 销售员、销售额 |
| 按地区 | 按地区汇总，销售额降序 | 地区、销售额 |
| 总览 | 总销售额 | 月度总销售额 |

金额列（单价、销售额、月度总销售额）均设置为 `0.00` 的两位小数格式。

## 8. 清洗与统计规则

### 8.1 清洗规则

按以下顺序执行：

1. 校验 6 个必需字段，缺失则报错并终止；
2. 删除 6 个字段中任意一个为空值 / NaN 的行；
3. 将数量、单价转换为数值，转换失败的行删除；
4. 过滤掉数量 ≤ 0 的行；
5. 按全部 6 个字段去重，保留第一条；
6. 清洗后若无数据，报错并终止。

空字符串和纯空白字符串按空值处理。

### 8.2 统计规则

- 销售额 = 数量 × 单价，保留 2 位小数；
- 按销售员、地区分组求和，按销售额降序排列；
- 总销售额为全部有效明细销售额之和；
- 金额计算使用 pandas 数值类型，输出格式为两位小数。

## 9. 异常场景说明

| 场景 | 脚本提示 | 行为 |
|---|---|---|
| 输入文件不存在 | `错误：输入文件不存在，请检查路径` | 终止，退出码 1 |
| 文件为空、损坏或不是有效 xlsx | `错误：无法读取 Excel 文件，文件可能为空或已损坏` | 终止，退出码 1 |
| 缺少必需字段 | `错误：缺少字段：日期、地区`（列出全部缺失字段） | 终止，退出码 1 |
| 清洗后没有有效数据 | `错误：清洗后无有效数据` | 终止，退出码 1，不生成报表 |
| 输出路径无权限或被占用 | `程序运行异常：<具体错误信息>` | 终止，退出码 1 |
| 其他未预期异常 | `程序运行异常：<具体错误信息>` | 终止，退出码 1 |

说明：

- 所有错误信息输出到控制台，退出码非 0，便于批处理脚本判断；
- 读取失败统一提示为“文件可能为空或已损坏”，不暴露底层堆栈；
- 字段缺失和无有效数据会保留具体原因，方便定位数据问题。
