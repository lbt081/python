## 一、看板场景

以“某电商平台 2024—2025 年销售数据”为业务场景，围绕销售额、订单量、客单价、利润率、退款率五个核心指标，构建一个可筛选、可联动、带预警的销售数据看板。

数据为模拟数据，共 5,626 条有效订单，覆盖：

- 时间：2024-01-01 至 2025-12-31
- 地区：华东、华南、华北、华中、西南、西北、东北
- 品类：数码家电、服饰鞋包、食品生鲜、美妆个护、家居日用、运动户外
- 渠道：APP、小程序、PC官网、线下门店

## 二、功能清单

### 基础任务

- 数据卡片：总销售额、订单量、平均客单价、利润率、退款率，并显示同比变化
- 折线图：月度销售额趋势，和上一年同期对比
- 柱状图：品类销售额与利润对比
- 环形图：渠道销售占比
- 明细表：订单级数据表，支持滚动查看

### 进阶任务

- 侧边栏筛选：日期区间、地区、品类、渠道，筛选后所有图表同步更新
- 页签切换：经营总览、品类分析、区域分析、明细数据
- 热力图：月份 × 品类销售额、渠道 × 地区销售额
- 矩形树图：品类 / 渠道销售贡献
- 雷达图：品类综合能力对比
- 仪表盘：2025 年度目标完成率
- 排行榜：省份销售额 TOP 10、省份经营明细
- 数据预警：利润率、退款率阈值可调，异常品类自动提示

### 扩展任务

- 深色科技风大屏视觉：渐变背景、发光卡片、统一图表主题
- 一键导出当前筛选结果为 CSV
- 数据清洗摘要查看

## 四、运行方式

```bash
# 1. 安装依赖
python -m pip install -r requirements.txt

# 2. 生成原始数据
python scripts/generate_data.py

# 3. 清洗数据
python scripts/preprocess.py

# 4. 启动看板
python -m streamlit run app.py
```

浏览器打开 `http://localhost:8501`。

如果系统提示 `streamlit` 命令被策略阻止，请使用 `python -m streamlit run app.py`，不要直接执行 `streamlit run app.py`。

## 六、数据清洗规则

1. 去除重复订单号；
2. 统一渠道写法（`APP `、`app`、`小程序 ` 等）；
3. 删除地区、品类、渠道、数量、单价等关键字段缺失的记录；
4. 剔除非正数单价、数量不在 1–8 的记录；
5. 按“数量 × 单价 × 折扣”重新计算销售额，修复负销售额；
6. 按品类毛利率回填异常成本，重新计算利润；
7. 评分裁剪到 3.0–5.0；
8. 派生年、月、季度、月份标签、星期等时间维度。

清洗前 5,716 条，清洗后 5,626 条。
